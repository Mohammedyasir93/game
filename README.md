# GameZone

A responsive gaming discovery website built with semantic HTML, CSS, and vanilla JavaScript. It runs locally without a build step or paid service.

## Run in VS Code

1. Open the `GameZone` folder in VS Code.
2. Open `index.html` directly in a browser, or install and start the Live Server extension from the editor.
3. With Live Server, right-click `index.html` and choose **Open with Live Server**.

## Included interactions

- Sticky navigation with responsive menu and smooth section links.
- Game genre filters and title search.
- Sample story and game-detail dialogs.
- Daily, weekly, and all-time sample leaderboards.
- Neon Click Challenge with a 30-second timer, touch/mouse input, score, and locally saved best score.
- Login/register demo modal with basic validation. Credentials are not sent or saved.

## Demo limitations

- Game covers and the hero use remote Unsplash images; an in-page color treatment appears if an image cannot load. Google Fonts also requires an internet connection, with local font fallbacks provided.
- News, ratings, leaderboard entries, and the profile are illustrative sample data, not live content.
- Login and registration are interface demonstrations only. There is no authentication, account creation, or password storage.
- The best mini-game score is stored in this browser's local storage. It is not synced between devices.
- Game detail and article dialogs contain sample copy. There are no game downloads, purchases, or external news integrations.
